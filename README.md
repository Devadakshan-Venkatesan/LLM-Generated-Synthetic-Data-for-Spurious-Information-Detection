# LLM-Generated Synthetic Data for Spurious Information Detection

This repository contains the code and prompts used for the MSc dissertation project:

**LLM Generated Synthetic Data for Spurious Information Detection**

The project investigates the use of LLM-generated synthetic Not-Spurious sentences to address class imbalance in spurious information detection.

Three LLMs were used for synthetic data generation:

- Qwen3-8B
- Llama 3.1-8B-Instruct
- Mistral-7B-Instruct-v0.3

## Contents

- `Final_Notebook.ipynb` — final experimental notebook
- `requirements.txt` — required Python packages
- `prompts/` — generation and verification prompts
